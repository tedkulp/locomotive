## Issue tracker

The spec and tickets for this app live in Forgejo at git.n3rd.cc/tedkulp/ansible (spec: tedkulp/ansible#18, tickets #19-#28), managed with the `fj` CLI. Always pass `-H git.n3rd.cc`, e.g. `fj -H git.n3rd.cc issue view tedkulp/ansible#19`.

Domain vocabulary (Controller, Playbook, Run, Working Copy, Schedule, Scheduler Ping, Drift) is defined in `GLOSSARY.md` of the tedkulp/ansible repo.
